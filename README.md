A complete full-stack blog website built with HTML, CSS, and JavaScript on the frontend and Node.js + Express on the backend, using a lightweight file-based database (NeDB) that requires zero installation.
🏠 7 fully linked pages — Home, Blog, Category, Single Post, Search, About, Contact
🔐 Admin authentication with JWT tokens and bcrypt password hashing
📝 Full blog post CRUD — create, read, update, delete posts via API
💬 Comment system with admin approval before comments go live
📬 Contact form that saves messages and sends email alerts to admin
🔍 Live search across posts by title, content, and tags
📧 Newsletter subscribe and unsubscribe system
🗄️ Auto-created file-based database — no MySQL or MongoDB needed
